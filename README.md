# Pennant Panic

A portrait-first, offline baseball franchise simulator.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Progress is saved automatically in the browser.

## Production build

```bash
npm run build
npm run preview
```

The production app is installable as a PWA and caches its application shell for offline use.

## GitHub Pages

Every push to `main` builds and deploys the game through GitHub Actions. In the repository's Pages settings, choose **GitHub Actions** as the source once; subsequent pushes deploy automatically.

## Current playable loop

- Choose one of 20 franchises and a season philosophy.
- Allocate development and decline points before each four-game series.
- Respond to trade offers, propose straight swaps, and sign free agents.
- Set a legal nine-player lineup and four-person starting rotation.
- Play batter by batter or skip ahead, with substitutions, handedness, hot/cold form, fatigue, and extra innings.
- Complete the 32-game season, postseason, retirements, departures, one-round draft, and offseason roster rebuild.
- Continue across unlimited seasons with franchise history, rivalry records, and Owner Legacy.
